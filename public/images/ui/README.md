# Куда положить фотографию фона

Сохрани присланную фотографию ткани сюда под именем:

    fabric-bg.jpg

Полный путь: `public/images/ui/fabric-bg.jpg`

Ничего больше делать не нужно — `PageBackground` уже ссылается на этот путь,
фон подхватится после обновления страницы.

Требования: JPEG, ширина от 1600 px, желательно не больше 400 КБ
(лишний вес бьёт по LCP, ТЗ п.7.2). Пока файла нет, на фоне
показывается тёплый градиент в тон палитре — сайт выглядит целым.

Сюда же кладётся `hero-workshop.jpg` — фотография мастерской
для первого экрана, когда она появится.
